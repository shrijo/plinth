# plinth

React + TypeScript + Vite, with [React Three Fiber](https://r3f.docs.pmnd.rs) and [drei](https://drei.docs.pmnd.rs).

## Scripts

```sh
pnpm install   # install dependencies
pnpm dev       # start the dev server
pnpm build     # type-check and build for production
pnpm preview   # serve the production build
pnpm lint      # run oxlint
```

## Layout

- `src/App.tsx` — the `<Canvas>` and scene setup (lights, environment, controls)
- `src/components/` — scene objects
